# Parent Teacher Conference Form

A simple and user-friendly **Parent Teacher Conference Form** built with HTML and CSS. The form allows parents or guardians to provide student information, contact preferences, and additional topics they would like to discuss during a parent-teacher conference.

##  Features

* Student information section
* Parent/Guardian information section
* Student grade input
* Preferred contact method
* Custom radio buttons
* Additional notes textarea
* Form validation using HTML
* Responsive centered layout
* Styled submit button with hover effect
* Dark blue themed interface

##  Technologies Used

* HTML5
* CSS3
* VS Code

##  Design

The project uses a **Midnight Blue** background with a semi-transparent form container and light text.

The form is divided into clear sections using:

* Fieldsets
* Legends
* Styled input fields
* Custom radio buttons
* A notes textarea
* Interactive submit button
